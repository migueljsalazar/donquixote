# Don Quixote, the game

A phone-first web game built on the story of Don Quixote. Every scene can be read two ways: what Sancho sees and what the knight sees. The more exciting reading costs you.

**Status:** concept stage. No path has been chosen yet.

- [`docs/deep-dive.md`](docs/deep-dive.md): what would make the game succeed, five possible directions, web versus iPhone app, and how building in the cloud works.
- [`prototype/index.html`](prototype/index.html): *A Two-Minute Sally*, a playable taste of the recommended direction. Thirteen scenes from Part One. It is one self-contained file with no build step. Open it in any browser.

## Playing it on a phone

Turn on GitHub Pages for this repository (Settings, Pages, "Deploy from a branch", `main`, `/ (root)`). The game is then at `https://migueljsalazar.github.io/donquixote/`. In Safari, Share and "Add to Home Screen" gives it an app icon.

## Sources and rights

The novel (1605, 1615), John Ormsby's 1885 English translation and Gustave Doré's 1863 engravings are in the public domain. Modern translations and the musical *Man of La Mancha* are not, and nothing here uses them. The prototype's artwork is original, and so is its text apart from a few short lines adapted from Ormsby.
